# 光的偵探社 — 光譜分析與應用 🌈

高中彈性學習課程（2 × 50 分鐘）· 國立潮州高中
SOIL 三段式互動教材：**4 段語音動畫 ＋ 5 個小遊戲 ＋ 10 題結業測驗**，單一 HTML、可離線使用。

🔗 **線上使用**：<https://tai-shengyeh.github.io/spectroscopy-lab/>

教材內容改編自 <https://tai-shengyeh.github.io/> 的光譜 × 食品分析系列課程，挑選對高中生最生活化、不需要數學的四個案例。

## 怎麼上課

直接用 Chrome 或 Edge 開啟 `index.html` 即可，不需要網路、不需要安裝。

| 操作 | 方式 |
|------|------|
| 換頁 | `←` `→`、空白鍵，或右下角 ‹ › 按鈕 |
| 全螢幕 | `F` 或右上角「全螢幕」 |
| 目錄（跳頁） | `M` 或右上角「目錄」 |
| 語音動畫 | 按「▶ 播放旁白」；可暫停、逐步、重播 |
| 教室沒有喇叭 | 勾選「無聲模式（只看字幕）」，動畫照常依字幕節奏播放 |

右上角會顯示每一頁的建議時間。網址加上 `#頁碼` 可直接開到該頁（例如 `index.html#13` 是第二節的第一頁）。

學生可以用手機或平板開上方的線上網址，自己玩小遊戲與測驗。更新教材後執行 `git add . && git commit -m "更新教材" && git push`，網址不變。

## 內容取材（課程網站 → 本教材）

| 本教材 | 取自 | 使用的事實 |
|--------|------|-----------|
| 硼砂偵探、檢量線 | 食品中硼酸（TFDAA0086） | 550 奈米、玫瑰紅／墨綠、示意檢量線 Abs = 0.095 × C、定量極限 300 mg/kg |
| 雞蛋新鮮度 | NIR 雞蛋新鮮度 | 30 顆褐殼蛋、第 0–21 天、660 筆光譜、740–1070 奈米、約 890／960／1020 奈米、室溫約 14 天 |
| 三聚氰胺、指紋比對 | RamanSPy × 食品分析 | 478 澱粉、676 三聚氰胺、850／1085／1125 醣類、1003 蛋白質、1156／1523 類胡蘿蔔素、1265–1745 油脂；偵測極限約 0.5%；Codex 嬰兒奶粉 1 mg/kg |
| XRF 元素解碼 | XRF × 食品分析 | 特徵能量 K 3.31、Ca 3.69、Fe 6.40、Cu 8.05、Zn 8.64、Rb 13.39、Sr 14.16 keV；應用案例為蜂蜜摻糖漿、番茄產地 |
| 光譜 × 電腦 | FTIR 咖啡 | 56 支樣本（Arabica 29、Robusta 27）、286 個波數、品種鑑別 100% |

教材中的光譜圖都是**示意圖**：峰的位置依上表，峰形、雜訊與 XRF 樣品組成為模擬，頁面上皆有標註。顏色實驗室的吸收峰位置（亮藍約 630、紅色 40 號約 504、薑黃素約 425、葉綠素約 430 與 662 奈米）為常見文獻的約略值，不是取自課程網站。

## 檔案與修改方式

```
spectroscopy/
├── index.html        ← 上課用（由 build.py 產生，請勿直接修改）
├── build.py          ← 把 src/、旁白與音檔組成單一 index.html
├── narration.json    ← 四段動畫的旁白（say＝朗讀文字，cap＝畫面字幕）
├── tts.py            ← 用 edge-tts 把旁白轉成 audio/*.mp3
├── audio/            ← 20 段旁白音檔（zh-TW-HsiaoChenNeural）
└── src/
    ├── body.html     ← 24 頁投影片與動畫 SVG
    ├── style.css
    └── app.js        ← 換頁、動畫播放器、互動元件、小遊戲、測驗
```

- 改投影片文字或題目：改 `src/body.html` 或 `src/app.js`，再執行 `python build.py`。
- 改旁白：改 `narration.json`，執行 `python tts.py`（需要網路）重新配音，再執行 `python build.py`。
